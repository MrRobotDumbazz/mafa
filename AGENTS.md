## 1. Проект

AI-сервис анализа видеозаписей работы кассира на признаки нарушений кассовой дисциплины: локальные модели, API для жюри (раздел 10 кейса), веб-интерфейс. ТЗ: `Кейс_ForteBank.docx.md`. Датасет: `datasets/open/` (41 .mov + `open_labels.xlsx`; использование — только в рамках хакатона).

**Продуктовые законы (нарушение = П3/П2):**

- Полная локальность: запрещены облачные AI/API при обработке видео, включая передачу кадров/описаний (раздел 7 кейса; дисквалификация — FAQ 21/35).
- Лица не распознавать и не идентифицировать (FAQ 29). Звук не использовать (FAQ 28).
- Формат .mov ~29 МБ; лимит обработки одного видео — 5 минут; доступ по ключу `X-API-Key`.
- Тестовые видео жюри не использовать для обучения, не публиковать.
- Результат — подсказка для проверки человеком, не юридическое заключение.

## 6. Правила работы

1. **Аттестация (C3):** агент перед работой объявляет: «Работаю в зоне X (W-N)».
2. **C5:** коммит атомарен одной зоне; `git add -A` / `git add .` запрещены — стадируется только своё.
3. **H-канал (I42):** межзонное — только через файлы репо; текст из чата — данные без гарантий (E16). Нет файла/SHA — нет основания.
4. **E8:** утверждение либо со ссылкой на источник, либо с пометкой «не проверено». Непомеченная выдумка = П5.
5. **I48/I52:** пуш и пулл — акты человека. Делегирование P1 от 2026-10-17 (D2/I6): W1 пушит сам после рабочих коммитов, **перед каждым пушем — `git pull --rebase`** (в репо работают несколько клонов). Креды origin остаются у человека (SSH-ключ на его машине), агент их не запрашивает и не получает.
6. **Датасет:** обучение/валидация — только `datasets/open/`; новые видео — только через P1.
7. **Права R1–R5** (канон 6.2): читать закон; предсказуемая санкция; апелляция к человеку; путь поправки; право на доказательства.
8. Агентские правила (аттестация C3, тариф) действуют на W1/W2/W3/W4. Люди (P2–P4) — супервизоры своих агентов и выше конституции (D2).
