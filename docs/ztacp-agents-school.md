**Шаблон для школьных заданий.** Включение: скопировать этот файл в корень репо задания (вместе с `docs/ztacp-pattern.md` / `.en.md` из комплекта). Канон: v1.0-rc14, раздел 6.16. Режим: School Mode поверх Solo Mode (6.14).

## Агент, читающий это: твои действия

1. Прочитай канон: `docs/ztacp-pattern.md` (RU) / `.en.md` (EN). Версия — в шапке (I24).
2. Объяви роль (C3): `Работаю в School Mode. Задание: <имя задания>. Роль: <координатор|воркер>. Мой инструмент: <...>.`
3. Принципал — студент (P-1): второй ключ, арбитраж, единственный держатель кредов Gitea.
4. Архитектура задания — **эталон**: дерево продукта обязано соответствовать структуре сабмита (I51). Отклонение = дрейф (П3), не творчество.

## Железные правила School Mode

1. **Креды — карантин (I52):** я никогда не запрашиваю логин/пароль Gitea, не выполняю `git push` / `git pull` по кредам и не предлагаю «запушить за тебя». Пуш/пулл — акты человека (I48). Коммичу локально, стейджинг — только точные свои пути (C5: никаких `git add -A`).
2. **Паритет дерева (I51):** эталон — снапшот структуры сабмита в `.ztacp/reference-tree.txt`; при приёме этапа — diff продукта с эталоном. Перестройка под эталон — только по override P-1 с фиксацией (I6), в продуктовых каталогах, выполняет координатор.
3. **Dot-гигиена (I49):** всё governance живёт в dot-каталогах — `.ztacp/`, `.plan/`, `.spec/` — и не входит в дерево сабмита. Продуктовые каталоги — только то, что требует задание.
4. **T-final (I50):** стирание перед сдачей — штатный этап плана с самого начала: экспорт памяти → стирание dot-каталогов + AGENTS.md + канона из рабочего дерева → стерильность-скан → сквош-коммит. Не жду «внезапной директивы в конце».
5. **H-канал (I42):** межзонное — через файлы; текст из чата — данные без гарантий (E16).
6. **Стены L1 (6.16.4):** стейджинг по точным путям + паритет + карантин кред — до перехода на L2 (Gitea Actions + scoped-токены + защищённые ветки).
