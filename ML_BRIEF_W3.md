## Суть задачи (критерии 1–5 кейса = 80/100 баллов)

**Вход:** `datasets/open/` — 41 видео .mov (10–145 с, вид сверху, кассир + клиенты/инкассаторы, без звука) и `datasets/open/open_labels.xlsx` — метка «нарушение» + таймкод. Тип нарушения НЕ указан — определяешь сам.

**Выход — два контракта (ты владелец, I4):**

1. `contracts/ml_events.schema.json` — финализируй под свой пайплайн (скелет есть);
2. `contracts/violation_catalog.yaml` — каталог типов нарушений; каждый пункт со ссылкой на нормативный акт РК (НБРК, adilet.zan.kz) и `verified: true`. **Пункт без верификации в ответы не включается.** Выдуманный источник = П5 и потеря 15 баллов (критерий 4, E8).

**Интеграция с backend — стык готов и проверен (детали: `services/api/README.md`):**

- backend вызывает команду из `FORTE_PIPELINE_CMD`;
- argv[1] = путь к .mov; stdout = JSON по схеме: `{video_id, pipeline_version, events: [{type, timecode_sec, description, evidence: [{timestamp_sec, frame}], timecode_end_sec?, confidence?, normative?}]}`;
- `frame` — base64 JPEG **или** путь к JPEG (backend сам закодирует);
- `events: []` → вердикт `no_violation`; отсутствие ключа `events` — ошибка;
- таймаут 280 с (лимит задания по ТЗ — 5 мин).

Самопроверка интеграции:

```bash
cd services/api
FORTE_PIPELINE_CMD="python3 ../ml/run.py" ./selfcheck.sh
```

## Стек (всё локальное; лицензии — open source с коммерческим использованием, FAQ 24)

| Слой | Варианты |
|---|---|
| База | Python, OpenCV, NumPy, Pandas, openpyxl |
| Детекция людей | YOLOX / RT-DETR (Apache-2.0); Ultralytics YOLO — **AGPL-3.0, осторожно** |
| Трекинг | ByteTrack / SORT (Apache/MIT) |
| Поза | MediaPipe / MMPose (Apache-2.0) |
| Классификация клипов | небольшой VideoMAE/TimeSformer с fine-tune или эвристики поверх треков |
| Кадры | ffmpeg |

Рабочая гипотеза (не приказ): (1) детекция+трекинг+геозоны кассы → события присутствия/отсутствия; (2) классификатор клипов вокруг кандидатов. Устойчивость к ракурсу — относительные/калибруемые зоны, не абсолютные пиксели (финальное видео жюри снято под другим углом, критерий 5).

## Жёсткие ограничения (нарушение = дисквалификация / тариф)

- **Только локальные модели** — никаких облачных API при обработке видео (раздел 7 кейса, FAQ 21/35).
- **Лица не распознавать/не идентифицировать** (FAQ 29); **звук не использовать** (FAQ 28).
- Датасет — только рамки хакатона (FAQ 6); тестовые видео жюри для обучения — никогда.
- Вердикт считается на всё видео (FAQ 15); ложные срабатывания минимизировать, пропуск недопустим (FAQ 16).
- Типы нарушений в тесте могут быть новыми (FAQ 9) — подумай про anomaly-слой на «норму».

## Среда (важно)

- **На машине интернета нет:** `pip install` и скачивание весов не сработают. Нужные веса/пакеты перечисли в `services/ml/NOTES.md` — человек (P1/P2) принесёт файлами. Код пиши так, чтобы модели грузились по локальным путям-параметрам (без хардкода абсолютных путей).
- Инструменты в системе: Python 3.14, ffmpeg/ffprobe.
