# AGENTS.md — зона tests (владелец P4)

Зона тестирования. Работает человек **P4 — своими руками, без ИИ-агента**. Если позже в зону сядет агент, он входит здесь как **W4** (полный вход по E6) и подчиняется этому файлу как закону.

## Границы

- Зона пишет: только `tests/**`.
- Читает всё — контракты это главный вход; продуктовые каталоги `services/*` не трогает.

## Задача зоны

- Контрактные тесты API против `contracts/api.openapi.yaml` (схема ответа жюри — раздел 10 кейса: `verdict`, `violations[]`, `timecode_sec`, `evidence_frames` base64 JPEG, `X-API-Key`).
- Holdout из `datasets/open/` для ML-метрик (recall-приоритет, FAQ 16).
- Проверка локальности: никаких внешних вызовов при обработке видео.
- Отказоустойчивость: битый файл, неверный ключ, неизвестный job_id, лимит 5 минут.
- Приёмочный прогон сценария жюри до сдачи.

## Правила

Межзонное — через файлы репо (I42); выводы тестов — с evidence: лог, SHA, артефакт (E11/E8); пуш — акт человека (I48). Для агента W4 (если появится): аттестация C3, стейджинг только своего (C5), права R1–R5 (канон 6.2), тариф (канон 6.3).

Закон: `docs/ztacp-pattern.md` (1.0-rc14).
