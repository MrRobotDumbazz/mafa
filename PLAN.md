## Решения координатора (H-канал, I42) — ответы на вопросы W2, 2026-10-17

1. **Ключ сайта:** принято. `/api/v1/*` (жюри) — ключ обязателен всегда, контракт раздела 10 ТЗ неизменен. Сайт ходит через префикс `/web/api/v1/*` без ключа (`FORTE_WEB_KEYLESS`, по умолчанию вкл) — браузер ключа не содержит и не спрашивает. KeyDialog — опциональный fallback на усмотрение W2/P3.
2. **Раздача статики:** берёт W1. Backend раздаёт `dist/` (`FORTE_STATIC_DIR`, SPA-fallback), nginx не нужен — один процесс на хосте. W2: production-сборка на машине с сетью: `VITE_USE_MOCK=false VITE_API_URL=/web npm run build` — относительный `/web` работает на любом адресе, пересборка под конкретный хост не нужна.
3. **Нормативы:** фронту менять ничего не надо — `violation.normative` приходит в ответе API. Backend подмешивает по `type` из `violation_catalog.yaml` только пункты с `verified: true` (реализация проверена). Задача W3 — заполнять каталог verified-пунктами; блок в карточке уже скрывается при отсутствии норматива.
