# Детальный отчёт зоны ml (W3) — для P2

Дата: 2026-10-17 (ночь). Покрытие: Этап 2 PLAN.md, пункты 1–4 + стык с backend (Этап 4, частично). Все артефакты — в `services/ml/`.

---

## 1. Резюме (executive summary)

- Построен **полный локальный конвейер** «.mov → детекция/трекинг → примитивы → rule-engine → события с нормативными ссылками → JSON + кадры-доказательства», интегрированный с backend (`SELFCHECK PASSED`).
- Нормативная база: 3 НПА (действующие ПП НБРК № 231 и № 120; № 58 — методологический) → **35 типов-гипотез с label** и маппинг всей ручной разметки.
- Метрики по видео-вердикту: v1 (YOLOv5n) holdout **recall 0.57 / precision 0.57 / FPR 0.50**; v0 (classic CV) — 0.71/0.56/0.67. Precision и FPR улучшены, recall просел — пороги v0 не перетюнены под детектор (следующий шаг, только на tune-наборе).
- Главный дефицит — **наблюдаемость жестовых и объектных типов** (документ, пересчёт, совмещение пачек, сейф, дверь): нужен дообученный детектор объектов и скелетная поза. Основа под них (примитивы, движок, каталог) готова.

## 2. Датасет (EDA)

42 видео .mov (портрет 464×848, ~30 fps, 12–142 с, медиана 23 с, ~280 МБ). Разметка: 22 «нарушение» / 20 «без»; у 20 нарушений есть гипотеза разметчика, X-32 и X-47 — без (X-47 автоматически пойман как violation). Отчёт: `research/eda_videos.md` (+.json).

## 4. Модель-формула (`model/`)

`Verdict = D_K1 ∨ D_K2 ∨ D_K3` — действия сотрудника ∨ клиента ∨ обстановки. Три рода отклонений: **пропуск обязательного шага**, **нарушение порядка**, **запрещённое действие/состояние**. Каждое срабатывание → Violation(label, окно, confidence, кадры). Нормативные планы Э1–Э7 (приём/выдача/обмен/кассация/пересчёт/инкассация/хранение) — декларативные данные (`scenarios.py`), движок на чистом Python, selfcheck 5/5. Формула и планы: `model/README.md`.

## 5. Слой восприятия

### 5.1 Окружение (была проблема — решена)
pip в среде заблокирован PEP 668 + TLS-сбои к PyPI. Решение: wheel-файлы качались curl'ом (с докачкой), установлены в `services/ml/.venv`: numpy 2.5.4, opencv-python-headless 5.0, pandas 3.0.6, openpyxl 3.1.5, onnxruntime 1.31.0. Итог: полный заявленный стек Python/OpenCV/NumPy/Pandas/openpyxl + ORT.

### 5.2 v0 → v1
- **v0 (classic)**: ffmpeg → grayscale PGM → дифф+дилатация → блобы → трекинг → EMA-фон. Работает без пакетов (fallback-режим `--backend classic`).
- **v1 (детектор)**: ffmpeg rawvideo 270×480@3fps → **YOLOv5n ONNX** (onnxruntime CPU, fp16, letterbox) → трекер ByteLite (IoU + центроида, скорость) → роли (кассир = самый постоянный трек) и зоны → стат-объекты (EMA-фон, персистентные ячейки, отношение по немаскированным пикселям) → примитивы. ~13–16 с на видео.
- YOLOX-ассеты GitHub (s/tiny) оказались дефектными (obj-ветка тождественный 0 при любом входе, проверено на cv2.dnn и ORT) — заменены на yolov5n v7.0 (3.98 МБ, декод в графе, люди 0.56–0.79 conf на наших кадрах).

### 5.3 Что детектируется сейчас
- Люди + перемещения, роли, зоны; уход с рабочего места; третий человек (появился после первого клиента, ≥3 с, рядом с зоной кассира).
- Стат-объекты (деньги/вещи, оставленные после ухода людей) → ROOM_MONEY_ON_TABLE / RECV_FUNDS_ACCESSIBLE-паттерн.
- COCO-объекты: сумки/рюкзак/чемодан (инкассация), телефон/бутылка/кружка/книга/мышь (лишние вещи → ROOM_PERSONAL_ITEMS), ноутбук/клавиатура (оборудование).
- Клипы (rule-based): service / solo_count / bag_incass / item_in_staff + взаимодействия (поза-прокси по близости треков).

### 5.4 Что НЕ детектируется (честно, и почему)
| Тип | Причина | Что нужно |
|---|---|---|
| ISSUE_NO_ID, RECV_NO_ID | удостоверение — вне COCO | кастомый детектор мелких объектов |
| ISSUE_NO_RECOUNT, RECV_NO_RECOUNT | жест пересчёта/аппарат не различим | скелетная поза (MediaPose нет на py3.14) |
| CASH_MIXED_WORN, RECV_MIXED_FUNDS | слияние стопок — жест высокого разрешения | поза + детекция купюр |
| ROOM_SAFE_OPEN, ROOM_KEY_ABANDONED, ROOM_DOOR_OPEN | сейф/дверь/ключ — вне COCO | кастомый детектор / калибровка зон |
| ROOM_LOW_LIGHT | автоэкспозиция камеры выравнивает яркость (X-15 ≈ X-1 по метрикам — проверено) | вероятно ненаблюдаемо принципиально |
| ANOM_CLIENT_LEFT_EMPTY | «пустые руки» — трекинг мелких объектов | детекция объектов в руках |

## 6. Метрики (holdout, seed 42: tune 29 / holdout 13; тюнинг — только tune)

| версия | recall | precision | F1 | FPR | таймкод ±10 с |
|---|---|---|---|---|---|
| v0 classic — tune | 0.80 | 0.57 | 0.67 | 0.64 | 8/15 |
| v0 classic — holdout | 0.71 | 0.56 | 0.63 | 0.67 | 4/7 |
| **v1 YOLOv5n — tune** | 0.60 | 0.47 | 0.53 | 0.71 | 7/15 |
| **v1 YOLOv5n — holdout** | **0.57** | **0.57** | 0.57 | **0.50** | 3/7 |

Разбор ошибок v1 (все случаи перечислены в `research/holdout_report_v1.md`):
- **FN (8 случаев)**: X-1 (сдача не посчитана), X-2/X-17 (документ), X-34 (ушёл без получения), X-33/частично X-11/X-30 (дверь), X-20 (сейф), X-44 (совмещение), X-38/X-46 (деньги доступны клиенту — маскируются кассиром). Все — из класса «ненаблюдаемо без жестов/объектов» (§5.4), кроме X-38/46 (порог маскировки — кандидаты на ретюн).
- **FP (13 случаев)**: два семейства — (а) ROOM_MONEY_ON_TABLE/CNT_UNATTENDED на чистых видео (X-12, X-23, X-25, X-29, X-27, X-43, X-8): легально оставленные/сдвинутые вещи переживают уход людей; (б) RECV_LEFT_STATION на чистых (X-35, X-39, X-48, X-5, X-14, X-19): кассир легально ходит по помещению — staff-зона по перцентилям слишком узкая. Оба семейства — стандартные кандидаты на ретюн порогов (min_dur/person-mask/cooldown) на tune-наборе без изменения архитектуры.

## 7. Продуктовые выходы

- `run.py` — вход для .mov: валидация, `--backend auto|dnn|classic`, авто-переисполнение через .venv; stdout JSON по контракту (схема `contracts/ml_events.schema.json` → **v1**: добавлен optional `summary` — вердикт, бэкенд, клипы, расшифровка label'ов; обратно совместимо).
- `batch_report.py` — отчёт по загруженным видео: вердикт + таблица «label → расшифровка → пункт ПП НБРК № 231» + клипы → `research/uploads_report_*.md/.json`.
- Кадры-доказательства: JPEG по таймкодам события (`run_evidence/`), до 3 на событие.

## 8. Интеграция с backend (стык Этапа 4)

`cd services/api && FORTE_PIPELINE_CMD="python3 ../ml/run.py" ./selfcheck.sh` → **SELFCHECK PASSED**: health / 401 без ключа / полный цикл (upload X-1.mov → job → вердикт → кадры) / 404 / keyless-путь web. Режим моков W1 может быть отключён.
