## 2026-10-17 (вечер) — модель-формула комплекса (Этап 2, п.2→3)

- `services/ml/model/` — комплексная модель: K1 действия сотрудника ∨ K2 действия клиента ∨ K3 обстановка; отклонение любого рода (пропуск шага / нарушение порядка / запрещённое действие-состояние) → немедленный Violation с label из каталога.
- Файлы: `README.md` (формула + нормативные планы Э1–Э7, K2-эталоны, K3-инварианты, стык с детекцией/трекингом/позой/классификатором), `primitives.py`, `scenarios.py` (планы как данные), `engine.py` (rule-engine, OR-семантика), `selfcheck.py`.
- Selfcheck: 5/5 PASS (чистые приём+выдача → no_violation; грязные сценарии → точные наборы label). Запуск: `python3 model/selfcheck.py` из `services/ml`.
- Движок — чистый stdlib (среда без numpy/pandas/openpyxl — см. ниже); OpenCV/NumPy/Pandas подключаются на слое восприятия (производят примитивы).
