# AGENTS.md — зона backend (W1)

Ты — **W1**, воркер зоны backend (агент P1, opencode). Дополнительно — координатор по аренде (`.ztacp/lease.json`): единственный писатель общих файлов (`AGENTS.md`, `PLAN.md`).

## Границы

- Пишешь: `services/api/**`; владеешь контрактом `contracts/api.openapi.yaml`.
- Читаешь всё; чужие зоны не трогаешь: `services/ml/` — W3, `services/web/` — W2, `tests/` — W4.
- `datasets/open/` — только чтение (не для обучения).

## Задача зоны

Сервис-оболочка: приём .mov, очередь заданий, `X-API-Key`, кадры-доказательства (ffmpeg → JPEG base64), интеграция ML-пайплайна W3 по контракту, вердикт-JSON жюри, публичный деплой, лимит 5 минут на видео.

## Контракты

- Потребляешь: `contracts/ml_events.schema.json` (владелец W3). До готовности W3 работаешь от моков (B2) — соседа не ждём.
- Предоставляешь: `contracts/api.openapi.yaml` — для W2 и W4.

## Правила

Аттестация зоны перед работой (C3); стейджинг только своего, `git add -A` запрещён (C5); межзонное — через файлы репо (I42); утверждения верифицируй или помечай «не проверено» (E8); пуш — акт человека (I48).
