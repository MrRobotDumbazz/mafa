# Контракты-швы (B1)

Единственные точки межзонного доверия. Меняет только зона-владелец (I4); потребители работают от схем и моков (B2).

| Файл | Владелец | Потребители | Статус |
|---|---|---|---|
| `api.openapi.yaml` | backend (W1) | frontend (W2), tests (P4) | draft 0.1 — по разделу 10 ТЗ |
| `ml_events.schema.json` | ml (P2) | backend (W1), tests (P4) | skeleton от Genesis — финализирует ml |
| `violation_catalog.yaml` | ml (P2) | все | skeleton от Genesis — типы и нормативы заполняет ml |

Правила изменений:

1. Изменение контракта = коммит владельца + bump версии в шапке файла.
2. Ломающие изменения — только с записью в `PLAN.md` (уведомление потребителей).
3. Потребителям запрещено ссылаться на внутренности соседа — только на эти файлы (B1).
4. Нормативные ссылки в `violation_catalog.yaml` действуют только с `verified: true` (E8 — выдуманный источник = П5, критерий 4 кейса).
