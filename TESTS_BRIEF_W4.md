## Чек-лист тестов (клади код в tests/**)

1. **Контрактные (по `contracts/api.openapi.yaml`):**
   - POST `/api/v1/analyze` multipart .mov → `{job_id, status: "processing"}`;
   - GET `/api/v1/jobs/{id}` → `processing|done|failed`; при `done`: `verdict: no_violation|violation`, `violations[]`: `type`, `timecode_sec`, `description`, `evidence_frames[1–3]` (`timestamp_sec` + `image_base64` JPEG), опц. `normative{document, clause, url}`;
   - без ключа → 401; неверный job_id → 404; не-.mov → 400; битый файл → 400 («File is not a readable video»); пустой ключ-конфиг → 503;
   - `/web/api/v1/*` — без ключа работает (маршрут сайта), `/api/v1/*` — строго с ключом;
   - `/health` — 200 без ключа.
2. **Локальность (критерий 7, дисквалификация):** при обработке видео — ноль внешних сетевых вызовов (аудит кода + runtime-проверка, например strace/подмена DNS — по возможностям среды).
3. **Отказоустойчивость:** обрыв соединения, повторная загрузка, большие файлы (лимит `FORTE_MAX_UPLOAD_MB`), статус failed с текстом ошибки, watchdog 5 мин (`FORTE_JOB_TIMEOUT_SEC`).
4. **Тайминги:** полный цикл одного видео ≤ 5 минут (раздел 10 ТЗ).
5. **Holdout-прогон:** `python3 services/api/eval41.py --out tests/eval41_report.json` (или в /tmp) — фиксируй метрики как evidence.
6. **Приёмочный сценарий жюри:** curl-флоу из раздела 10 ТЗ от начала до конца; отчёт.
